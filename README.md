# EP6 Logger — обновления Android

Этот публичный репозиторий служит **только для распространения подписанных APK** EP6 Logger. Исходный код приложения здесь не размещается.

## Скачать приложение

После первого опубликованного релиза:
- [Последний релиз](https://github.com/WWWorm92/ep6-logger-releases/releases/latest)
- [Скачать EP6-Logger.apk](https://github.com/WWWorm92/ep6-logger-releases/releases/latest/download/EP6-Logger.apk)
- [Контрольные суммы](https://github.com/WWWorm92/ep6-logger-releases/releases/latest/download/SHA256SUMS.txt)

Приложение проверяет новые версии при запуске, показывает список изменений и после согласия пользователя загружает APK. Установка подтверждается в системном установщике Android.

Обновления должны быть подписаны тем же ключом, что и уже установленная версия. В каждом релизе публикуются `EP6-Logger.apk` и `SHA256SUMS.txt`. Не устанавливайте APK из неизвестных источников.

> Репозиторий не предназначен для секретов, персональных токенов, ключей подписи или исходных файлов диагностических записей.
